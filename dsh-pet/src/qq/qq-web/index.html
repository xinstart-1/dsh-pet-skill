一键装网关

插件里已经带了 NapCat 官方安装器（只带安装器，不带 QQ 客户端——那份由安装器从腾讯官方渠道下载）。 点「解压安装器」后运行里面的 NapCatInstaller.exe，安装目录请填下面这个路径； 装完点「写入配置」，端口、消息格式和令牌会自动配好并回填到上面，你不用手抄。

安装器是图形界面：选目录、下载 QQ 内核、扫码登录这三步必须你自己点，插件替代不了。 装好后用小号扫码，别用日常号。

现在什么情况

手动发一句

这是你自己的操作，不走白名单、不看试运行开关——人工路径与服务路径分开，和抖音那边一致。

回不回

试运行打开时，照常生成回复、写审计，但一条都不发。第一次接上网关先跑这个： 看看它打算怎么说话，比直接上线安全得多。

怎么回

越大越连贯，也越容易被旧语气带偏；0 = 只回这一句
这段时间一条都不回（主人私聊也不回）
到 之间随机等一下——秒回很像机器人

群里叫这些名字也算叫它

群里不一定有人会 @，叫一声名字也要能接话。两个字以上才生效，空 = 只认 @。

白名单

私聊填 QQ 号，群聊填群号

空着就谁都不回（主人私聊除外，见「主人私聊必回」）。群聊要求群号在这张表里， 并且有人 @ 了它或叫了名字——被拉进陌生群时，@ 一下不足以让它开口。

黑名单

这里面的号（或群）无论白名单怎么写都永不回复。

熟人名单

只影响语气，不改人设

它是怎么工作的

QQ ⇄ 网关（OneBot v11）⇄ 本插件 ⇄ 宿主 LLM

消息从网关推过来 → 过闸门（开关 / 黑名单 / 白名单 / 静默时段 / 频率）→ 借宠物的人设 → 由宿主的大模型写一句 → 发回去。模型不由本插件配置，用的是 harness 里那个默认模型。

风险，说在前面

  • 网关是第三方程序，登录机器人号有被风控 / 封号的可能。用小号，别用主号。
  • 本插件不下载、不启动、不注入任何 QQ 客户端，也不替你同意任何协议。
  • 没有批量发送、没有群发、没有好友申请——一个无鉴权的本地端口不该有那种能力。
  • 默认总开关关、试运行开。你不手动打开，一句话都不会发出去。

装一个网关

  1. 装网关：用上面「一键装网关」那块最省事（解压安装器 → 跑一次安装器 → 写入配置）。不想用内置安装器的话，自己下载也行：首选 NapCat（Windows 一键包，默认 WS 端口 3001），也可 LLBot、SnowLuma。Lagrange 已归档，不要选。
  2. 用它登录你准备的 QQ 小号（扫码）。
  3. 在它的设置里打开正向 WebSocket——NapCat 里是建一个「WebSocket 服务器」，不是「WebSocket 客户端」（配反了它会主动来连你，插件永远等不到连接）。记下端口（默认 3001），设一个令牌。
  4. 回到「连接」页填地址与令牌 → 保存 → 连接 → 看登录号对不对。
  5. 先在「聊天」页开着试运行发一条私聊，确认回复的样子，再关掉试运行。
