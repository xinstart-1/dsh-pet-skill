网关

对话本身只走一条 WebSocket：网关推事件过来，插件回调用。网关可以是你在 NapCat（首选，Windows 有一键包）／LLBot（原 LLOneBot）／SnowLuma 里自己装的，也可以由上面的 「一键安装」装进插件自己的目录——两边都只是在本机 127.0.0.1 上说话。你在网关里登录小号， 把它的正向 WebSocket 地址填进来即可。

一键装网关

插件里已经带了 NapCat 官方安装器（只带安装器，不带 QQ 客户端——那份由安装器从腾讯官方渠道下载）。 点「① 一键安装」就全自动：解压安装器 → 后台跑完（下载 QQ 与网关 → 解压 → 装配）， 装到 napcat/app/ 下；装完点「② 一键连接」，端口、消息格式和令牌会自动配好 并回填到上面，你不用手抄。

安装器没有界面，也不用选目录：它把 QQ 与网关解压进插件自己的目录 napcat/app/（解出约 1.15GB），不碰你系统里装的 QQ。 全程唯一要你亲手的，是最后用小号扫码登录——那必须是账号主人本人，别用日常号。

「① 一键安装」是全自动的：不用你去任何窗口里点东西，安装器在后台跑完 （自动从腾讯官方下载 QQ 并解压进 napcat/app/）。装好后再点 ② 即可。 网络慢时 QQ 那段 300MB 是大头；重跑会跳过已下好的安装包（它留在 napcat/QQ.exe）。

失败了直接再点一次就行：下载中断会留下截断的安装包，安装器自己不会察觉， 于是每次都卡在同一处。插件在每次安装前会检查 QQ.exe 与 NapCat.Shell.zip 是否完整，发现截断就自动删掉重新下载； 安装失败后也会立刻清一次。你不需要手动删文件。

网关包由插件先下好再交给安装器：安装器自己下 NapCat.Shell.zip 时 不校验长度，镜像把 34MB 截成 4MB 它也报「下载成功」，接着解压就失败—— 这是「每次都失败」的真正原因。所以插件会先按官方元数据（大小 + SHA-256）自己下一份， 校验通过才放进安装器的工作目录，让它跳过那段不可靠的下载。 拿不到就退回安装器自己的路子，不会因此装不了。

下载最新安装器：当随包那份过旧或解压失败时，从这里从 GitHub 拉最新版 （边下边校验 SHA-256，校验不过的包会直接丢弃），落在本机数据目录，优先级高于随包内置。

它是怎么工作的

QQ ⇄ 网关（OneBot v11）⇄ 本插件 ⇄ 宿主 LLM

消息从网关推过来 → 过闸门（开关 / 黑名单 / 白名单 / 静默时段 / 频率）→ 借宠物的人设 → 由宿主的大模型写一句 → 发回去。模型不由本插件配置，用的是 harness 里那个默认模型。

风险，说在前面

  • 网关是第三方程序，登录机器人号有被风控 / 封号的可能。用小号，别用主号。
  • 插件不碰你系统里装的 QQ：内置安装器把 QQ 与 NapCat 解压进插件自己的数据目录 （napcat/app/），那是一份独立的便携副本；你日常那个 QQ 不参与、不被改，也不会替你同意任何协议。
  • 网关进程由插件在你要用时拉起、由「停止」杀回（taskkill /T），退出插件不留孤儿——但它仍是第三方程序，注入的是那份副本。
  • 没有批量发送、没有群发、没有好友申请——一个无鉴权的本地端口不该有那种能力。
  • 默认总开关关、试运行开。你不手动打开，一句话都不会发出去。

装一个网关

  1. 装网关：用上面「一键装网关」那块最省事（① 一键安装全自动跑完，② 一键连接自动写配置并连上）。 不想用内置安装器的话，自己下载也行：首选 NapCat（Windows 一键包，默认 WS 端口 3001），也可 LLBot、SnowLuma。Lagrange 已归档，不要选。
  2. 用它登录你准备的 QQ 小号（扫码）——这是全程唯一要你亲手做的一步。
  3. 在它的设置里打开正向 WebSocket——NapCat 里是建一个「WebSocket 服务器」，不是「WebSocket 客户端」（配反了它会主动来连你，插件永远等不到连接）。记下端口（默认 3001），设一个令牌。 走内置「② 一键连接」时这一步插件已经替你写好配置，可以跳过。
  4. 回到「连接」页填地址与令牌 → 保存 → 连接 → 看登录号对不对。
  5. 先在「聊天」页开着试运行发一条私聊，确认回复的样子，再关掉试运行。

卸载与清理

在 DSH 里移除插件只会停掉运行中的进程，不会自动删掉用户数据。本插件在 %DSH_HOME%/dsh-pet-qq（QQ 网关、登录态、配置）、 %DSH_HOME%/dsh-pet（宠物配置与素材）以及可选的 %DSH_HOME%/electron（约 104MB 运行时，可重下）都落了盘。

正确的卸载顺序：先点下面的按钮清理，再去 DSH 插件页移除。 如果直接在插件页删了插件也没关系——插件在卸载时会自动清掉 napcat/（网关安装器与已装网关，实测约 1.5GB，可重下）， 但配置与 QQ 登录态会留在磁盘上，需要手动删掉 %DSH_HOME%/dsh-pet-qq 与 %DSH_HOME%/dsh-pet。

关于 QQ 客户端本体：NapCat 的安装器是把 QQ 解压进插件自己的目录 （napcat/app/NapCat.*.Shell/，解出约 1.15GB；外加留在 napcat/QQ.exe 的 300MB 安装包，重跑时靠它跳过下载），不是装到系统的 C:\Program Files，也不改系统 QQ 的注册表项。所以上面的清理会把「① 一键安装」装出来的那份 QQ 和网关一起删干净，不会在你系统里留一个陌生 QQ；你日常用的 QQ 是另外装的，不受影响。

下面的按钮会立即删除上述目录——QQ 小号的登录态与全部配置都会丢失，且不可恢复。 请在确实要卸载时再点，并先确认已保存好需要的素材/配置。清完仍需你到 DSH 里把插件移除。
