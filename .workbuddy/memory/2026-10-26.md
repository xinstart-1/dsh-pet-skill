## 新建插件：dsh-pet-douyin（抖音分享，dsh-pet 第三方扩展）

- 位置：`X:/Agent/deepseek插件/dsh-pet-douyin/`（手写 ESM，无构建步骤，`lib/index.js` 是宿主入口）
- 用户选定的方案：**仅半自动辅助发布**（不接抖音开放平台 OAuth，因为 `video.create.bind` 只对企业主体开放）、**本地文件夹监听**、**定时 + 右键菜单 + 对话命令三入口**。
- 能力：扫目录挑片 → ffmpeg 转 9:16（可选，缺 ffmpeg 降级为原样复制）→ 生成发布包（video / 文案.txt / 说明.txt / 封面.jpg / meta.json）→ 文案进剪贴板 + 打开抖音创作者中心上传页 → 台账去重 + 节奏限速。
- 模块：`config`（扁平字段清单归一化）、`caption`（模板变量）、`schedule`（五道闸纯函数）、`media`、`pack`、`ledger`、`pet-bridge`（dsh-pet HTTP）、`service`（门面）、`router`（`/dsh-douyin-7341`）、`web/`（无框架设置页）。
- 测试：`node --test "test/*.test.js"` → 30 项全绿（含无 ffmpeg 的降级路径、HTTP API、去重）。
- 预览：`node scripts/preview.mjs 7341` → `http://127.0.0.1:7341/dsh-douyin-7341/`（临时 DSH_HOME，不碰真实配置）。
- 踩过的坑：`dsh plugin` 的 patch id 必须等于包名；packer 要读 `config.pack.outDir` 而不是默认 packs 路径；工作状态清理计时器必须 unref，否则 `node --test` 会挂 15 秒；配置归一化只对「真丢信息」告警（补 `#`、补扩展名点不该报警）。
